# Contributing to EduTest Generator

Thank you for your interest in contributing to EduTest Generator! This document provides guidelines for contributing to this Progressive Web App.

## 🤝 How to Contribute

### Reporting Issues
- Use GitHub Issues to report bugs or suggest features
- Provide clear description and steps to reproduce
- Include browser/device information for bugs

### Development Setup
1. Fork the repository
2. Clone your fork: `git clone https://github.com/YOUR-USERNAME/edutest-generator-pwa.git`
3. Create a feature branch: `git checkout -b feature-name`
4. Make your changes
5. Test on multiple browsers and devices
6. Commit with clear messages
7. Push and create a Pull Request

### Code Style
- Use consistent indentation (2 spaces)
- Add comments for complex functionality
- Follow existing code patterns
- Test PWA features on mobile devices

### PWA Guidelines
- Maintain offline functionality
- Ensure service worker updates properly
- Test installation on iOS and Android
- Keep manifest.json updated
- Optimize for performance

### Feature Requests
- Open an issue first to discuss the feature
- Explain the use case and benefits
- Consider backward compatibility

## 📋 Development Guidelines

### Testing
- Test on real mobile devices
- Verify PWA installation works
- Check offline functionality
- Validate in multiple browsers

### Documentation
- Update README.md for new features
- Document API changes
- Include deployment instructions
- Add screenshots for UI changes

## 🚀 Release Process

1. All changes must pass mobile testing
2. PWA features must work offline
3. Service worker must update correctly
4. GitHub Pages deployment must succeed

## 📞 Getting Help

- Open an issue for questions
- Check existing documentation
- Review deployment guide

Thank you for contributing!
